# Maritime Vessel Detection (CVOD01) — Requirements & Implementation Checklist

## Project Information
- **Task Code:** CVOD01
- **Role:** Computer Vision Engineer
- **Target Problem:** Accurate, real-time detection of maritime vessels, with specific focus on small, distant, and low-contrast targets in coastal and open-sea RGB imagery and video.
- **Primary Dataset:** SeaShips (7,000 images, 1920×1080 resolution, 6 vessel categories).
- **Hardware Profile:** NVIDIA GeForce RTX 3050 Laptop GPU (4GB VRAM, CUDA 12.1).
